# i18n.js

静的ウェブサイト向けの、依存関係のない軽量な国際化スクリプトです。ブラウザの設定またはURLパラメータに基づいて、日本語のコンテンツを英語に翻訳します。

このスクリプトはシンプルに設計されています。ソースのHTMLが日本語であることを前提とし、日本語以外のユーザー向けに英語へ翻訳します。

## 機能

- **テキスト置換**: `translation.json` ファイルを使用して、特定の要素のテキストコンテンツを翻訳します。
- **コンテンツの表示/非表示切り替え**: 検出された言語に基づいて、コンテンツのセクション全体を表示または非表示にします。
- **言語検出**: URLパラメータ (`?lang=...`) からユーザーの言語を特定するか、ブラウザの言語設定にフォールバックします。
- **シンプルなロジック**: 検出された言語が日本語 (`ja`) でない場合のみスクリプトが実行されます。

## 使い方

1. **HTMLにスクリプトを追加する**
   `</body>` 閉じタグの前に以下の行を配置します。モジュールとして読み込む必要があります。
   ```html
   <script type="module" src="translation.js"></script>
   ```

2. **`translation.json` ファイルを作成する**
   HTMLファイルと同じディレクトリに `translation.json` ファイルを作成します。このファイルには翻訳用のキーと値のペアを記述します。キーには日本語のテキスト、値には英語の翻訳を指定します。
   ```json
   {
     "日本語": "Japanese",
     "英語": "English"
   }
   ```

3. **翻訳対象のコンテンツにタグを付ける**
   HTMLファイル内で翻訳したいコンテンツをマークアップするには、以下の2つの方法のいずれかを使用します。

### 方法1: テキストノードの翻訳

単語やフレーズ単位の翻訳には、日本語のテキストを含む要素に `ja` クラスを追加します。スクリプトはこの要素を見つけ、そのテキストコンテンツを `translation.json` の対応する英語の値に置き換えます。

**例:**
```html
<p>This word is <span class="ja">日本語</span>.</p>
```
日本語以外のユーザーがアクセスすると、スクリプトは以下のように変換します:
```html
<p>This word is <span class="ja">Japanese</span>.</p>
```

### 方法2: コンテンツブロックの表示/非表示切り替え

より大きなコンテンツブロックの場合は、日本語版に `.ja_content` クラスを、英語版に `.en_content` クラスを使用します。日本語以外のユーザーに対しては、スクリプトがすべての `.ja_content` 要素を非表示にし、すべての `.en_content` 要素を表示します。

**例:**
デフォルトで英語のコンテンツを非表示にするために、少しのCSSを追加する必要があります。
```html
<div class="ja_content">
  <p>これは日本語のコンテンツです。</p>
</div>
<div class="en_content">
  <p>This is the English content.</p>
</div>

<style>
  .en_content { display: none; }
</style>
```

## 言語検出

言語は以下の優先順位で決定されます:
1. **URLパラメータ**: URLに `?lang=en` や `?lang=ja` を追加することで、言語を強制的に指定できます。
2. **ブラウザ設定**: URLパラメータが見つからない場合は、ブラウザの言語設定 (`navigator.language`) を使用します。
3. **デフォルト**: 言語を特定できない場合は、デフォルトで英語 (`en`) になります。

スクリプトは、成功した翻訳や見つからない翻訳キーをブラウザの開発者コンソールにログ出力します。
